# Mode: tech-talk — 10 slides, demo-led arc

Live demo with a narrative spine. The deck carries the story; the demo
carries the proof. Slides never duplicate what the demo shows.

## Arc (10 slides)

1. Title — photo-hero: product + name + one-line promise. Notes: the
   30-second hook, spoken, not read.
2. Problem — display-type: one painful sentence at 72pt. Notes: the
   anecdote that makes it real.
3. Why now — photo-collage: 2–3 tiles of the old way failing.
4. Live demo anchor — showcase: near-black stage, one screenshot raster
   of the thing about to run live. Notes: exact demo script + fallback
   if the network dies.
5. How it works — duo boxes (layouts §patterns): two mechanisms max.
6. Code moment — mono textbox, ≤12 lines, ≥14pt. Notes: narrate lines
   1–3, skip the rest.
7. Proof — giant stat + one tile. Digits morph-tween from slide 5's
   numbers where possible.
8. Trade-offs — two pills: what it doesn't do. Honesty slide.
9. Roadmap — flow pills, 3 steps max.
10. Close — framing close: ask + mono contact line. Notes: the sentence
    you want quoted.

## PPTX notes

- Moving object: the product raster (slides 1 → 4 → 7).
- Raster floor is heavier here: demo screenshots count as rasters —
  capture at 1920px, never photograph a screen.
- Entrances: code slide gets none (static, readable instantly).
