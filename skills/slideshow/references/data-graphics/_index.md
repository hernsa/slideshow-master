# Data graphics — index

> Diagrams, charts, and tables for PPTX decks. All native shapes —
> SmartArt, screenshots, and SVG never appear on slides.

| File | Covers |
|---|---|
| [diagrams.md](./diagrams.md) | duo boxes, forks, flow pills (native shapes) |
| [charts.md](./charts.md) | giant stats, native charts, last-resort tables |
| [tables.md](./tables.md) | table construction detail + handout rule |

## Picker

1. One number to prove → giant stat (`charts.md` §1).
2. Trend/comparison → native chart, ≤5 categories (`charts.md` §2).
3. Structure/choice → duo boxes or fork (`diagrams.md` §1).
4. Sequence → flow pills (`diagrams.md` §1).
5. Nothing else fits AND rows ≤4 → table (`tables.md`).
